# Asta Classic — Tabellone interattivo

Tabellone per l'asta del fantacalcio Classic: spunta i giocatori chiamati, segna i tuoi obiettivi, registra gli acquisti con crediti residui calcolati in automatico.

## Uso
Apri `index.html` (o la pagina pubblicata via GitHub Pages). Tutto gira nel browser, nessun server richiesto.

**Salvataggio**: usa i pulsanti 💾 Salva / 📂 Carica in alto per esportare e ripristinare il progresso su file, così non perdi nulla chiudendo la pagina.
